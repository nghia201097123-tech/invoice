| Cấu trúc               | Markdown                       | Kết quả                      |
| ---------------------- | ------------------------------ | ---------------------------- |
| Tiêu đề                | `#`, `##`, `###`               | `<h1>`, `<h2>`, `<h3>`       |
| In đậm                 | `**text**` hoặc `__text__`     | **text**                     |
| In nghiêng             | `*text*` hoặc `_text_`         | *text*                       |
| Gạch ngang             | `~~text~~`                     | ~~text~~                     |
| Danh sách không thứ tự | `-`, `*`, `+`                  | Danh sách                    |
| Danh sách có thứ tự    | `1.`, `2.`                     | Danh sách                    |
| Link                   | `[OpenAI](https://openai.com)` | [OpenAI](https://openai.com) |
| Hình ảnh               | `![alt text](link)`            | ![img](link)                 |
| Code inline            | `` `code` ``                   | `code`                       |
| Khối code              | <pre>` ```js`</pre>            | Khối code có màu             |
| Trích dẫn              | `> nội dung`                   | > nội dung                   |
